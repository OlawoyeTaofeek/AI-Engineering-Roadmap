# Explanation

Conceptual write-ups, kept separate from code so they can be read start to
finish without jumping between files.

- `architecture_overview.md` -- decoder-only transformer, end to end
- `attention_mechanisms.md` -- self / causal / multi-head, with the reasoning
  for why each design choice exists
- `normalization.md` -- LayerNorm, RMSNorm, pre-norm vs post-norm
- `training_objective.md` -- cross-entropy / negative log-likelihood, why it
  works, how it connects to maximum likelihood estimation
